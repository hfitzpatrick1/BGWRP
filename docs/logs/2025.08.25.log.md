# 2025.08.25 - Grid Pattern Artifact Investigation

## Primary Issue: Periodic Grid Patterns in Waterfall Plots
DAS waterfall plots showed regular grid/pixelation artifacts with 16-25 second temporal periodicities, initially suspected to be pipeline aliasing effects.

## Root Cause Analysis

### Initial Hypothesis: Pipeline Aliasing
**Suspected**: Decimation artifacts from 100Hz→1Hz downsampling causing visual grid patterns
- **Decimation factor**: 10 (config.decimation_factor)
- **Nyquist compliance**: 16-25 second periods (0.04-0.06 Hz) well below 0.5 Hz Nyquist limit
- **Initial assessment**: Should not cause aliasing at observed frequencies

### Systematic Pipeline Stage Analysis
**File**: `src/diagnostic/analyze_pattern_progression.m` (created)
- **Method**: Quantitative pattern strength measurement across pipeline stages
- **Stages analyzed**: Raw TDMS → TDMS-to-MAT → Concatenated
- **Metrics**: Temporal/spatial pattern strength, channel coherence, overall pattern score

### Key Discovery: TDMS Conversion Artifact Source
**Critical Finding**: Pattern progression analysis revealed:
```
Stage           Overall Score   Temporal Strength   
RAW             96.9            0.0%               
TDMS_TO_MAT     105.2           6.9%               
CONCATENATED    104.8           8.0%               
```

**Conclusion**: Grid patterns introduced during TDMS→MAT conversion (8.6% increase), not during decimation (0.4% change)

## TDMS Conversion Scaling Analysis

### Modified Raw Analysis Diagnostic
**File**: `src/diagnostic/analyze_grid_pattern.m`
- **Problem**: Original "raw" analysis applied same scaling as pipeline (1/8192 × 116)
- **Fix**: Removed scaling operations (lines 200-202) to analyze truly raw ADC values
- **Result**: Raw TDMS data showed different frequency patterns than processed data

### Frequency Evolution Through Pipeline
**Raw TDMS (100Hz)**: 0.04-0.08 Hz patterns (25, 16.67, 12.5 second periods)
**TDMS→MAT (100Hz)**: 3-14 Hz patterns (high frequency artifacts introduced)
**Concatenated (1Hz)**: 0.43-0.45 Hz patterns (decimated from TDMS→MAT artifacts)

**Critical Insight**: The visual grid patterns (0.15-0.33 Hz in final plots) are **not** the same as raw sensor periodicities

## Root Cause: Two-Stage Scaling Quantization

### Silixa Conversion Process Analysis
**File**: `src/prepare/Silixa_TDMSDataToPhysicalDispRate.m`
```matlab
% Lines 98-102: Problematic two-stage scaling
adc_scalar = 1/8192;           % Stage 1: ADC normalization
data = data * adc_scalar;      
data = 116 * data;             % Stage 2: Physical units conversion
```

**Problem**: Sequential floating-point operations introduce cumulative quantization artifacts
**Evidence**: 
- Raw ADC values: [-20,125, 19,798] counts (clean)
- After scaling: [-331, 347] nm/sample (periodic artifacts appear)

### Web Research: Limited Precedent
**Finding**: No specific documentation of grid patterns in DAS waterfall plots
**Related**: "Striping artifacts" in DAS literature caused by:
- Interrogator electronic noise
- High sampling rate electronics issues  
- System-level coherent noise patterns

## Mitigation Strategies Tested

### Analysis-Stage Filtering
**Approach**: Post-processing filter application during analysis
**Methods tested**:
- `run_detrend`: Linear trend removal (minimal impact on periodic artifacts)
- `run_highpass`: Remove low frequencies (modest improvement)

**Assessment**: Analysis-stage filtering provides some improvement but doesn't address root cause

### Advanced Processing Options
**File**: `src/config.m` - Available but not optimal for this artifact type
- Chen denoising framework: Targets different noise types
- Spatial median filtering: For cross-channel coherent noise
- Dynamic bounds optimization: Improves visualization, not underlying data

## Technical Findings

### Pattern Characteristics
- **Temporal dominance**: Strong temporal patterns, minimal spatial patterns
- **Channel coherence**: 0.97-0.98 across all pipeline stages (systematic artifacts)
- **Frequency shift**: Artifacts migrate from 3-14 Hz → 0.43-0.45 Hz through decimation
- **Data type**: Raw TDMS data stored as `single` (32-bit float), not integer ADC counts

### Pipeline Architecture Assessment
**Current approach placement**: Analysis-stage filtering (correct)
- Preserves raw data integrity
- Allows flexible experimentation
- Avoids expensive preprocessing overhead

**Alternative**: Preprocessing-stage filtering (not recommended)
- Permanent data modification
- Inflexible for different analysis requirements
