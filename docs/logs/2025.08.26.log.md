# 2025.08.26 - Grid Pattern Filtering Assessment & Strategic Plan

## Problem Statement
DAS waterfall plots show persistent grid pattern artifacts with 16-25 second temporal periodicities that mask subtle aquifer response signals in pump test analysis.

## What We've Definitively Established

### ✅ Root Cause Confirmed
- **Grid patterns exist in raw sensor data** - Visual comparison showed raw TDMS vs processed data appear identical
- **Not processing artifacts** - Patterns are real sensor characteristics (environmental vibrations, fiber optic sensor behavior)
- **Amplified by scaling** - 11.1% quantitative increase during TDMS→MAT conversion due to scale amplification making existing patterns detectable
- **Source**: Environmental vibrations, fiber optic sensor behavior, or acquisition system artifacts

### ✅ Pipeline Analysis Complete
- **TDMS conversion stages tested** - Single-step vs double-precision scaling (no improvement)
- **Decimation not the cause** - Grid patterns exist before decimation stage
- **Data format confirmed** - Issue persists across different processing methods

## What We've Tried (Filter Testing)

### ❌ Failed Approaches

#### 1. Chen et al. Framework (Incomplete Implementation)
**What we tested:**
- Basic median filtering labeled as "Chen Stage 2"
- Simple bandpass filter (Stage 1)
- Basic F-K FFT operations (Stage 3)

**Why it failed:**
- **Not actually Chen techniques** - Missing core innovations:
  - No plane wave destruction for slope estimation
  - No local flattening along structural directions
  - No structure-oriented median filtering
- **Wrong application domain** - Chen designed for earthquake detection (high-frequency), not pump test analysis (low-frequency aquifer responses)
- **Signal destruction** - Reduced amplitude by ~50% ([-127.465, 102.384] → [-64.753, 40.045])

#### 2. Spatial Median Filtering
**What we tested:**
- 21-channel spatial median across adjacent channels
- Temporal smoothing with 3-sample window

**Why it limited:**
- Targets vertical striping, but our grid patterns are more complex
- Too gentle to affect the persistent temporal periodicities
- Preserves signal but doesn't address core grid pattern frequencies

#### 3. Temporal Filtering
**What we tested:**
- Moving average and moving median filters
- Various window sizes (3-17 samples)

**Why it failed:**
- Grid patterns have 16-25 second periods (well within signal bandwidth)
- Cannot separate grid artifacts from aquifer response signals
- Risk removing actual pump test signals

### ✅ Baseline Established
- **No filtering** provides cleanest view of actual data
- **Fixed plot bounds** (-0.25 to 0.05 nm/s) enable consistent comparison
- **Visual assessment** shows filtering either ineffective or signal-destructive

## Technical Analysis

### Grid Pattern Characteristics
- **Temporal periodicity**: 16-25 second cycles (0.04-0.06 Hz)
- **Spatial coherence**: High (0.97-0.98 across channels)
- **Amplitude**: Comparable to aquifer response signals
- **Persistence**: Consistent across all datasets and processing methods

### Signal Preservation Requirements
- **Aquifer responses**: Low-frequency, long-term trends
- **Drawdown signals**: Gradual changes over minutes/hours
- **Spatial coherence**: Expected for geological formations
- **Dynamic range**: Small signals (-0.25 to 0.05 nm/s range critical)

## Strategic Assessment

### Why Previous Approaches Failed

#### 1. Wrong Problem Framing
- **Treated as "artifact" to eliminate** → Actually inherent sensor characteristic
- **Applied earthquake DAS techniques** → Pump test has different signal characteristics
- **Focused on aggressive filtering** → Pump test requires signal preservation

#### 2. Incompatible Filter Design
- **Chen framework**: Designed for high-frequency earthquake detection
- **Our data**: Low-frequency aquifer responses in same band as "noise"
- **Result**: Filters remove signal along with patterns

#### 3. Fundamental Conflict
- **Grid pattern frequencies**: 0.04-0.06 Hz
- **Aquifer response frequencies**: 0.001-0.1 Hz  
- **Overlap**: Cannot filter one without affecting the other

## Recommended Strategic Plan

### Phase 1: Accept and Characterize (Immediate)
**Approach**: Stop fighting the grid patterns, characterize them as sensor noise floor

**Actions:**
1. **Document grid pattern characteristics** systematically
2. **Establish signal-to-noise metrics** for each dataset
3. **Develop noise-aware analysis techniques**
4. **Focus on signal extraction** rather than noise removal

**Rationale**: Grid patterns are real sensor characteristics, not eliminable artifacts

### Phase 2: Smart Signal Enhancement (Medium-term)
**Approach**: Enhance signal visibility without aggressive filtering

**Potential techniques:**
1. **Adaptive visualization** - Dynamic contrast enhancement
2. **Differential analysis** - Compare pre/post pump signals  
3. **Spatial averaging** - Combine multiple channels for trend extraction
4. **Statistical detection** - Signal detection in presence of known noise

**Rationale**: Work with the noise rather than against it

### Phase 3: Alternative Sensor Validation (Long-term)
**Approach**: Validate DAS findings with independent measurements

**Options:**
1. **Head data correlation** - Use pressure transducer data as ground truth
2. **Inter-channel consistency** - Exploit spatial redundancy in DAS
3. **Temporal baseline** - Compare with pre-pumping periods
4. **Cross-validation** - Multiple DAS acquisition settings

**Rationale**: Confidence in results despite visual artifacts

## Immediate Next Steps

### 1. Abandon Active Filtering
- **Disable all experimental filters**
- **Return to baseline processing** (movmean smoothing only)
- **Focus on visualization improvements**

### 2. Implement Noise-Aware Analysis
- **Quantify grid pattern strength** per dataset
- **Develop SNR metrics** for each analysis window
- **Create uncertainty estimates** for extracted parameters

### 3. Enhance Signal Detection
- **Multi-channel averaging** for trend extraction
- **Statistical significance testing** for detected changes
- **Correlation with head data** for validation

## Conclusion

Grid patterns are **inherent sensor characteristics**, not eliminable processing artifacts. Aggressive filtering destroys the subtle aquifer response signals we need to preserve. 

**Strategic pivot**: From "artifact elimination" to "signal extraction in presence of known noise."

**Success metric**: Reliable aquifer parameter estimation despite visual grid patterns, validated against independent pressure transducer measurements.
